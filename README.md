# math-concepts
Interactive, visual math puzzles that help young kids learn early math concepts through play.

## Puzzles

| Puzzle | What it teaches | Open |
| --- | --- | --- |
| [Shape Balance](balance-scale/) | Balance-scale shape puzzles (early algebra): remove matching shapes from both sides, find what weighs the same, then balance a new scale. Random puzzles with Easy, Medium and Hard levels. | Open `balance-scale/index.html` in any browser |
